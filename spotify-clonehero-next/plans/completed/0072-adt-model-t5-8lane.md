# 0072 — ADT model swap: t4 (9-lane) → t5 (8-lane, Arm A s0)

Update the drum-transcription CRNN from the deployed `t4`/diagJ checkpoint to
`t5` (Arm A s0, v3 recipe), exported from the drum-to-chart repo as:

- `https://assets.musiccharts.tools/models/crnn_stereo_256mel_t5.onnx` (94,683,794 B)
- `https://assets.musiccharts.tools/models/crnn_stereo_256mel.t5.thresholds.json`

Source of truth for the swap: `drum-to-chart/docs/2026-07-30-ship-handoff-armA_s0.md`.

## This is NOT a drop-in weight swap

t5 is a **schema change**: the head is **8 lanes**, not 9. `crash-2` is gone
and **ride slides from index 8 to index 7**.

```
t4: [kick, snare, high-tom, mid-tom, floor-tom, hihat, crash, crash-2, ride]
t5: [kick, snare, high-tom, mid-tom, floor-tom, hihat, crash, ride]
```

Verified against the ONNX itself: `logits` output is `[1, 500, 8]`; inputs
(`mel [1,2,256,500]`, `context [1,5120]`) are unchanged, so mel/context/
windowing code is untouched.

crash-2 was a structurally-dead lane (0 GT positives) that t4 suppressed with a
`2.0` "never fire" threshold, so **no user-visible crash-2 note has ever been
produced** — the app's own `CRNN_THRESHOLDS[7] = 2.0` plus the postprocess
crash-2→crash promotion guaranteed it. Dropping the class is therefore not a
behavior regression for existing charts.

Thresholds (val-tuned, Arm A s0's own vector, 8-wide):

```json
[0.5, 0.55, 0.65, 0.65, 0.7, 0.65, 0.7, 0.65]
```

## Decode contract for 8 lanes

Taken from the research repo's own taxonomy-conditional 8-lane branches —
`autoresearch-toms/train_ab.py:make_predict_fn` (the path that actually
produced Arm A s0's scored predictions) and
`autoresearch-adt/analysis/hardneg_kill_gate.py:apply_deploy_post_block`,
which are required to stay identical to each other:

| constant         | t4 (9-lane)         | t5 (8-lane)           |
| ---------------- | ------------------- | --------------------- |
| `TOM_LANES`      | `[2,3,4]`           | `[2,3,4]` (unchanged) |
| `CYMBAL_LANES`   | `[5,6,7,8]`         | `[5,6,7]`             |
| `LANE_CONFLICTS` | `(5,2) (8,3) (6,4)` | `(5,2) (7,3) (6,4)`   |
| crash-2 promote  | applies             | **removed**           |

The crash-2 promotion must be deleted, not ported: at 8 lanes index 7 is ride,
so running it would move ride energy into crash and then suppress ride.

   - `__tests__/class-mapping.test.ts`, `peak-picking.test.ts`,

   - `crnn-logits-reference-t5.json` — new fixture; `crnn-logits-reference.test.ts`

## Ship decision (Eli, 2026-07-30)

**Shipped.** The two questions this plan raised are both resolved:

- **Decode condition.** armA_s0 is confirmed under BOTH decode conditions
  (tom-reorder ON and OFF), and its tuned threshold vector is **bit-identical
  across the two**. The exported ONNX + thresholds are therefore valid as-is
  at the app's setting. `TOM_REORDER` stays `false`.
- **Timing constants unchanged.** `SYSTEMATIC_ONSET_MS_CHART_FLOW` (0 ms) and
  `SYSTEMATIC_ONSET_MS_AUDIO_FLOW` (7 ms) carry over to t5 — no retune
  required, so the P8 offset probe does not gate this ship.

Product expectation: **0.3342 val-tuned**.

## Still open (not blocking, not this repo)
