# scripts/lib

Node helpers the audio, render and QA tools share. Nothing here imports
React.

| Module        | What                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cli.ts`      | `parseFlags` (strict `node:util` parseArgs), the flag readers `need`/`num`/`positive`/`int`/`frameRange`/`intList`, `isMain` (a module is a CLI only when run directly), `runCli` (usage errors exit 2, failures print one line and exit 1; set `DEBUG` for the stack), `loadData`/`importExport`/`moduleExports` (a JSON file or a module's export, returned as `unknown` for the tool to check)                                            |
| `check.ts`    | Checks for data that arrives as `unknown`: `checkNumber` (with `min`, `above`, `max`, `integer`; it returns the number, or undefined once it has recorded the problem), `checkString`, `checkArray`, `checkRecord`, and `throwProblems`, which fails naming every problem at once. The tools' assertion functions (`assertSoundtrackConfig`, `assertCues`, `assertArrangement`, `assertPacingSheet`) are built from them and narrow the type |
| `proc.ts`     | `run`, `ffmpeg` and `ffprobeJson`, which throw with the tail of stderr when a tool exits non-zero; `ffmpegArgs`, the preamble every ffmpeg call starts with (`-hide_banner -nostdin -v error`); `streamRecords` for fixed-size records (raw video frames) from a child's stdout                                                                                                                                                              |
| `bt709.ts`    | BT.709 limited range for H.264 made with ffmpeg: `BT709_TAGS` (the four `-color_*` options), `BT709_H264_METADATA` (a bitstream filter that retags in place) and `bt709Filter({from: 'rgb' \| 'yuv', width?, height?, pixFmt?})`, the conversion (and lanczos scale) that ends with the frames tagged, which ffmpeg 8 needs for the tags to stick                                                                                            |
| `files.ts`    | Atomic writes (`writeFileAtomic`, `writeJsonAtomic`, `produceAtomic` for tools that write the file themselves), scratch folders under `$TMPDIR` that are always deleted, even on an interrupt                                                                                                                                                                                                                                                |
| `cleanup.ts`  | `onInterrupt`: scratch folders, temporary outputs and bundles are removed on Ctrl-C or a kill too (Node runs no `finally` then)                                                                                                                                                                                                                                                                                                              |
| `media.ts`    | ffprobe: size, frame rate, colour tags, exact frame counts, the first frame's decode delay                                                                                                                                                                                                                                                                                                                                                   |
| `numbers.ts`  | `maxOf`/`minOf` for lists of any length (spreading a long list into `Math.max` overflows the stack)                                                                                                                                                                                                                                                                                                                                          |
| `remotion.ts` | The shared film flags, `bundleFilm` (the kit's product-app webpack override, a fresh bundle folder, deleted after), `openRenderSession` (one Chrome for every still), `frameFile`, `strideFrames`                                                                                                                                                                                                                                            |

## The flag vocabulary

Every tool in `scripts/audio`, `scripts/render`, `scripts/qa`, `blender`,
`scripts/recorder` and `scripts/new-film.ts` spells the same thing the same
way. Frame numbers are film frames unless a tool says the numbers are the
clip's own (motionAudit's `--range`). A negative value is written with `=`
(`--from=-30`); `--from -30` reads `-30` as a flag.

| Flag                                                                                                                          | Means                                                                                                                                                  | Used by                                                                                       |
| ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| `--frames 12,40,96`                                                                                                           | A list of frames, always                                                                                                                               | `stills.ts`, `logo_sting.py`, the recorder's `record.mjs` (with `--keep`)                     |
| `--range 300-420`                                                                                                             | An inclusive range of frames (`300` alone is one frame)                                                                                                | `renderFilm.ts`, `strip.ts`, `checkFrames.ts`, `motionAudit.ts`, the recorder's `record.mjs`  |
| `--every 15`                                                                                                                  | The step through a range or a clip                                                                                                                     | `strip.ts`, `checkFrames.ts`, `contactSheet.ts`                                               |
| `--from 600`                                                                                                                  | The film frame something starts on: a clip's first frame, the sting's frame 0                                                                          | `mux.ts`, `contactSheet.ts`, `stingEvents.ts`, `logo_sting.py`                                |
| `--length 90`                                                                                                                 | A count of frames                                                                                                                                      | `sfx.ts`, `stingEvents.ts`, `logo_sting.py`, the recorder's `selftest.mjs`                    |
| `--chunks 0-749,750-1424`, `--chunk-size 600`                                                                                 | A list of ranges, a count of frames                                                                                                                    | `renderFilm.ts`                                                                               |
| `--tolerance 3`                                                                                                               | Levels (0-255) a pixel may differ by; the default is `FRAME_TOLERANCE` in `render/compareFrames.ts` for both tools                                     | `compareFrames.ts`, `checkFrames.ts`                                                          |
| `--min-run-sec`, `--flash-window-sec`, `--preroll-sec`, `--handle-sec`, `--clock-start-sec`, `--tolerance-ms`, `--timeout-ms` | Anything that is not frames carries its unit                                                                                                           | `motionAudit.ts`, `stingEvents.ts`, the recorder, `mux.ts`/`deliver.ts`, `renderFilm.ts`      |
| `--app-url <url>`                                                                                                             | The running app's page (a URL)                                                                                                                         | the recorder's `record.mjs` and its app adapters                                              |
| `--app <dir>`                                                                                                                 | The product app's root folder, when it is not the default                                                                                              | `new-film.ts`                                                                                 |
| `--chart <folder>`                                                                                                            | A chart folder (notes.chart or notes.mid, song.ini, audio). An app adapter that loads several charts names each one: `--chart <name>=<path>`, repeated | `soundtrack.ts`, `highwaySync.ts`, `highway/link-chart.ts`; the chart-editor recorder         |
| `--timeline <file>`                                                                                                           | The film's timeline: timeline.json, or a module exporting it                                                                                           | `stingEvents.ts`, `highwaySync.ts`, the recorder (with `--storyboard <module>`)               |
| `--crf <n>`                                                                                                                   | The x264 quality of an encode                                                                                                                          | `renderFilm.ts`, the recorder (with `--preset`, `--pix-fmt`)                                  |
| `--in`, `--out`, `--out-dir`, `--keep <dir>`, `--report <file.json>`                                                          | The input, the output file or folder, a folder to keep what would otherwise be deleted (rendered frames, a take's PNGs), the report                    | throughout                                                                                    |
| `--export <name>`                                                                                                             | Which export of a module to read (a config, cues, an arrangement, a pacing sheet, a timeline)                                                          | `soundtrack.ts`, `sfx.ts`, `loopBed.ts`, `pacingAudit.ts`, `stingEvents.ts`, `highwaySync.ts` |
