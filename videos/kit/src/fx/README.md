# fx

Light, lens and motion effects. Every effect is a pure function of the film
frame (`useGlobalFrame`), timed with the composition's fps and sized from its
format, so the same call looks the same at 30 or 60 fps, at 720p, 1080p or
4K, and in portrait.

```tsx
import {
  CameraShake,
  Flash,
  Grain,
  Shockwave,
  SparkBurst,
  Vignette,
} from '@musiccharts/video-kit/fx';

const {cx, cy} = useFormat();
<AbsoluteFill>
  <CameraShake at={hit}>
    <Hero />
    <Shockwave at={hit} x={cx} y={cy} rings={2} color={color.purpleHot} />
    <SparkBurst at={hit} x={cx} y={cy} count={56} />
  </CameraShake>
  <Flash at={hit} origin={{x: cx, y: cy}} />
  <Vignette />
  <Grain />
</AbsoluteFill>;
```

## Units

- Every `at`, `exitAt` and other point in time is a FILM frame.
- Durations passed as props (`duration`, `decay`, ...) are frames; their
  defaults are written in seconds and converted with the composition's fps.
  A prop in seconds says so in its name (`lifeSec`, `streakSec`, `riseSec`).
- Speeds and rates are per second (`speed`, `gravity`, `drift`, `rate`), so
  they hold at any frame rate. `MotionBlur`'s velocity is per frame: it is
  how far the element moved since the last frame.
- Positions and sizes you pass are px of the composition. Defaults are
  reference px (px on a 1080 short side) scaled by `useFormat().unit`.
- Nothing takes a frame override: to re-time an effect, wrap it in the
  clock's `TimeShift`.

## Rules

- **Grain never touches the product highway.** Grain is a layer blended over
  everything under it, so it changes those pixels. On a highway shot, leave
  it out (`<BrandStage grain={false}>`) or keep it under the highway.
- **DepthOfField renders its children twice** (a blurred pass and a sharp
  masked pass). Never wrap WebGL in it: the highway or any three.js canvas
  would run two renderers at twice the cost, and they could disagree. Wrap
  DOM planes only. `SampledMotionBlur`, `LightSweep` and `MotionBlur`'s
  smear duplicate their children too.
- Filters cost area times radius: wrap the moving element, not the frame.
  The blocks skip a filter whose value would not show.
- One shockwave, one flash per moment, in the moment's accent; shake only
  the hero hits.
